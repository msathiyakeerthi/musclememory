      What session 7 starts with

      How honest is this? The store, the guards, the review pipeline, the counters and the CLI are the real library. In an offline run two parts are rule-based stand-ins: the agent (it reads its own learned context and runs the steps written in whichever skill it loads) and the reviewer (it reads the transcript from the real review prompt). No branch anywhere looks at the session number.

      Reproduce it: python examples/multi_session_demo.py, or python examples/multi_session_demo.py --real to let Claude be both the agent and the reviewer.
