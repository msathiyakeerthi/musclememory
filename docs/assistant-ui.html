Muscle Memory

The assistant that stops asking you the same thing

Twelve chats over six days with one household. Nobody configures anything and no model is retrained. After each chat, the assistant writes down what it should have known — and reads it back the next time.

Day one

Two weeks later

1. It has a conversation

Nothing special happens during the chat. The assistant answers as usual, and the person gets their reply without waiting.

2. A reviewer reads it afterwards

A second pass over the finished chat asks one question: is there anything here worth knowing next time? Usually the answer is no.

3. The next chat starts with it

What it wrote is a plain text file. It goes into the next conversation, so the assistant begins already knowing.

A real run of the open-source library, replayed here: the memory entries and the written procedures are the exact files it produced. Offline, the assistant and the reviewer are rule-based stand-ins, so the demo is reproducible without an API key — the store, the safety rules and the review pipeline are the real thing. github.com/msathiyakeerthi/musclememory
